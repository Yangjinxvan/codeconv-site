# Changelog

本项目所有重要版本变更记录。

## [10.10.0] - 2026-09-27

### ✨ 新增
- CLI 参数：--version/-v 查看程序版本号
- CLI 参数：--help/-h 显示帮助
- CLI 参数：--quiet/-q 静默模式，跳过欢迎页
- CLI 参数：-e/--encode 文本转十进制编码值
- CLI 参数：-d/--decode 十进制编码值还原文本
- CLI 参数：-i/--input、-o/--output 文件输入输出转换
- stdout/stderr 分流，出错时返回非 0 退出码
- 四个平台自包含便携版（.NET 6/.NET 10 × x86/x64），解压即用
- 官网提供安装包与便携包下载，附 SHA256 校验码

### 🛠 安装程序增强
- .NET 运行时已安装检测，避免重复下载
- .NET 下载失败弹窗提示
- PATH 环境变量读写加固，管理员模式写入系统 PATH，卸载安全清理
- 安装包 SHA256 完整性校验

### 🐛 修复
- 程序嵌入应用图标，窗口与任务栏显示自定义 logo
- 网站 favicon 使用统一图标
- 统一全部源码、脚本、网页文件行尾为 CRLF
