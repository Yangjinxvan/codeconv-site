Features

为编码处理设计的功能

每一个功能都服务于一件事：让你在终端里把字符和字节的关系看得清清楚楚。

双向即时转换

字符到字节码、字节码到字符，两种模式一键切换。整串文本或空格分隔的编码串批量处理，回车即出结果。

双编码体系

Windows-1252 全 256 字节映射与纯 ASCII（0–127）两套模式，覆盖西欧语言符号、标点与未分配区段，映射关系一目了然。

控制字符识别

NUL 到 DEL 的 33 个控制字符全部命名枚举，解码时直接输出 [NUL]、[CR] 这样的名称，不再是一堆不可见字符。

插件扩展

实现 IContract 接口的 DLL 放入 plugins 目录即可注册新命令，命令冲突时会让你选择保留哪个插件，扩展完全自主。

日志与崩溃转储

Serilog 按天滚动日志，单文件自动限额；意外崩溃时自动写出日志与内存转储文件，问题可回溯、可排查。

彩色终端界面

基于 Spectre.Console 的 ANSI 配色、进度条与结构化提示，错误、警告、成功各有颜色，批量大时也能看清进度。

FAQ

常见问题

支持中文输入吗？+
编码模式下，中文不在 Windows-1252 / ASCII 的可表示范围内，会如实标记为 [不支持:中]，不会静默乱转。解码模式只接受 0–255 范围内的数值，超出范围提示无效。
一次能转换很多个吗？+
可以。解码模式输入空格分隔的编码串（如 72 101 108 108 111）即可一次还原整句；编码模式直接输入整段文本，逐字符转换并带进度条。
需要安装 .NET 运行时吗？+
发布的 exe 是框架依赖版：net10.0 版本需要 .NET 10 运行时，net6.0 版本需要 .NET 6 运行时。如未安装运行时，可在安装程序中勾选安装对应版本的运行时（默认勾选）。
插件怎么安装？+
把实现了 IContract 接口的 DLL 放到系统共享目录 C:\ProgramData\codeconv\plugins 下，启动时自动扫描加载。多个插件命令冲突时，程序会提示你保留旧插件还是使用新插件。
32 位和 64 位怎么选？+
x86 版本兼容所有 Windows 环境，处理普通输入完全够用；x64 版本适合大量数据的批量转换场景，前提是机器具备对应架构的 .NET 运行时。
